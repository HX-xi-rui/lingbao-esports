# 电竞AI应用创新与实践 - 智慧电竞互动平台

## 1. Concept & Vision

**产品名称**: 「灵宝百事通」- 电竞IP智慧交互平台

**核心理念**: 连接电竞文化与现实世界，让每一位电竞爱好者都能与喜爱的角色、选手建立深度情感羁绊，探索电竞文旅新体验。

**用户价值**:
- 沉浸式体验电竞IP世界观
- 与AI角色进行智能对话互动
- 探索电竞主题文旅目的地
- 感受赛事精神与团队羁绊

## 4. Features & Interactions

### 核心功能模块

#### 4.1 赛事精神传递
- **功能描述**: 展示王者荣耀职业赛事精彩片段、战队数据、选手荣誉
- **交互方式**: 
  - 点击卡片展开详情
  - 时间轴滑动浏览赛事历程
  - 实时数据更新动画

#### 4.2 选手羁绊系统
- **功能描述**: 选手虚拟形象展示，个人故事，羁绊关系图谱
- **交互方式**:
  - 3D旋转卡片展示选手
  - 羁绊关系连线动画
  - 点击展开个人主页

#### 4.3 电竞文旅探索
- **功能描述**: 电竞主题城市目的地、游戏内景点打卡
- **交互方式**:
  - 地图交互探索
  - VR全景预览入口
  - 打卡任务系统

#### 4.4 AI智能对话 (腾讯混元集成)
- **功能描述**: 与电竞角色AI进行实时对话
- **交互方式**:
  - 角色选择 → 进入对话
  - 自然语言输入
  - 对话历史记录
  - 导出对话功能
- **AI角色**:
  - 亚瑟·战意 - KPL赛事解说，分析战队战术、预测比赛结果
  - 妲己·荣耀 - 荣耀导师，分析英雄克制、推荐上分技巧、制定训练计划
  - 马可·旅者 - 电竞文旅向导，探索电竞城市线下体验

#### 4.5 俱乐部展示
- **功能描述**: 展示KPL俱乐部卡片，包含logo、名称、缩写等信息
- **交互方式**:
  - 点击卡片展开俱乐部详情
  - 查看俱乐部选手列表
  - 查看俱乐部赛程信息
- **视觉设计**:
  - 俱乐部logo自适应缩放
  - 智能背景处理（自带圆形边框的logo不显示白色背景）
  - 悬停效果与动画

## 6. Technical Approach

### 技术栈
- **前端**: HTML5 + CSS3 + Vanilla JavaScript
- **动画**: CSS Animations + Canvas粒子效果
- **AI集成**: 腾讯混元大模型 API (TokenHub)
- **数据**: 本地JSON模拟数据
- **后端**: Python HTTP服务器 (带CORS代理)

### 架构设计
```
├── index.html (主页面)
├── server.py (本地开发服务器 + API代理)
├── css/
│   └── bonds.css (全局与组件样式)
├── js/
│   ├── app.js (主逻辑)
│   ├── chat.js (AI对话模块)
│   ├── components.js (UI组件)
│   ├── config.js (配置文件)
│   ├── data.js (模拟数据)
│   ├── utils.js (工具函数)
│   └── api.js (API封装)
└── images/
    ├── club/ (俱乐部logo)
    └── heroes/ (英雄头像)
```

### 腾讯混元集成方案
1. 通过TokenHub接口调用混元大模型
2. 自定义对话界面UI (打字机效果、消息气泡)
3. 后端代理处理CORS跨域问题
4. 支持多场景切换（亚瑟·战意/妲己·荣耀/马可·旅者）
5. API Key安全存储 (localStorage)

## 8. 俱乐部Logo优化方案

### 问题
- 部分俱乐部logo自带圆形白色背景
- 部分logo需要白色背景衬托
- 不同logo尺寸不一，需要统一展示

### 解决方案
1. **智能背景处理**
   - 检测logo是否自带圆形边框
   - 自带圆形边框的logo显示透明背景
   - 无圆形边框的logo显示白色背景

2. **自适应缩放**
   - 每个logo单独配置缩放比例
   - 保持logo居中对齐
   - 详情页与列表页样式统一

3. **图片缓存优化**
   - 头像切换时使用缓存
   - 避免每次重新加载导致的闪烁
